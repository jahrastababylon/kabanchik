# Dzikie Korytarze — как запустить

Рабочая версия: **https://jahrastababylon.github.io/kabanchik/** (после включения GitHub Pages, см. ниже).

В папке:

| Файл | Что это |
|---|---|
| `index.html` | всё приложение |
| `manifest.webmanifest`, `sw.js`, `icon-*.png`, `apple-touch-icon.png` | установка на телефон как приложение (PWA) |
| `supabase_v4.sql` | миграция базы (нужна только для режима с настоящей базой) |

Без ключа Supabase приложение работает в **демо-режиме**. Примерные метки появляются вокруг того места, где ты находишься, а твои отметки сохраняются только в этом браузере.

## GitHub Pages (основной способ)

Код лежит в репозитории `jahrastababylon/kabanchik`. Включить один раз:
**Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.**
Каждый новый коммит в `main` обновляет сайт через 1–2 минуты.

Старая версия v2 (Google Maps) сохранена в истории: коммит `98d010b`.

## Вариант А. Netlify Drop (без git)

Подходит для проверки на телефоне, в любой стране и для отправки ссылки другим.

1. Распакуй архив. Должна получиться папка `dzikie-app` с `index.html` внутри.
2. Открой в браузере на компьютере: **https://app.netlify.com/drop**
3. Перетащи **всю папку** `dzikie-app` в окно браузера.
4. Через несколько секунд появится ссылка вида `https://случайное-имя.netlify.app`. Открой её на телефоне.
5. Нажми «Зарегистрироваться / Claim site», иначе сайт может быть удалён. Хватит бесплатного аккаунта.
6. Чтобы обновить версию: Netlify → твой сайт → **Deploys** → перетащи новую папку.

Сайт работает по https, поэтому браузер разрешит геолокацию и карта откроется там, где ты стоишь.

**Установить на телефон как приложение:**
- Android (Chrome): меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- iPhone (Safari): кнопка «Поделиться» → «На экран Домой».

## Вариант Б. Локально на компьютере

1. Открой Терминал (Mac/Linux) или PowerShell (Windows).
2. Перейди в папку: `cd путь/к/dzikie-app`
3. Запусти сервер: `python3 -m http.server 8000` (на Windows иногда `python -m http.server 8000`).
4. Открой в браузере **http://localhost:8000**
5. Остановить сервер: `Ctrl + C` в терминале.

Не открывай `index.html` двойным кликом. Подложка карты и геолокация требуют адрес `http://localhost` или `https://`.
С телефона по Wi-Fi (`http://192.168.x.x:8000`) карта откроется, но геолокация работать не будет. Для теста на телефоне используй вариант А.

## Вариант В. Постоянный адрес (Vercel)

1. Зарегистрируйся на https://vercel.com (бесплатный тариф Hobby).
2. Открой **https://vercel.com/drop** и перетащи папку `dzikie-app`.
3. В настройках проекта можно привязать свой домен.

## Подключить настоящую базу (Supabase)

Ключ `anon public` уже вписан в `CONFIG.SUPABASE_ANON_KEY`. Он публичный по замыслу, данные защищает RLS в базе.

1. Supabase → **SQL Editor** → New query → вставь весь `supabase_v4.sql` → **Run**. Должно быть «Success». Запускать v3 не нужно.
2. Supabase → **Authentication → Providers → Anonymous** должен быть включён (уже включён с v2).
3. Обнови страницу приложения.

Пока миграция не запущена, приложение покажет предупреждение и будет работать в демо-режиме.

**Фото (v5).** Чтобы фото хранились в Supabase Storage, а не текстом в базе, один раз запусти `supabase_v5_photos.sql` в SQL Editor. До этого фото продолжают сохраняться по-старому, ничего не ломается.

**Птицы и названия (v6).** Запусти `supabase_v6_birds.sql`. Он добавит вид «Ptak 🐦», поменяет иконку «Inne» на 🐾 и сделает название обязательным для птиц и прочих животных. Пока миграция не запущена, приложение работает как раньше, только без птиц.

## Языки

Интерфейс на польском и английском. Язык выбирается по настройкам телефона или браузера: польский для `pl`, английский для всех остальных. Вручную его можно сменить в Atlas → Settings, а также на первом экране. Названия видов и поведения хранятся в базе по-польски и переводятся при показе.

## Карта

- Стиль карты выбирается в Atlas → Settings → Map style: OpenStreetMap, OpenFreeMap (Liberty, Positron, Bright, Dark — бесплатно, без ключа), CARTO (нужен `CARTO_KEY`). Стиль по умолчанию задаётся в `CONFIG.DEFAULT_STYLE`.
- По умолчанию подложка **OpenStreetMap**: весь мир, без ключа. Для теста и пилота этого достаточно.
- Перед публичным запуском возьми бесплатный ключ **CARTO**: https://carto.com/basemaps/apikey/ (аккаунт не нужен, некоммерческое использование бесплатно до 5 млн запросов в месяц). Вставь его в `CARTO_KEY`. Подложка станет аккуратнее, появится тёмная тема, и ты не будешь зависеть от лимитов OSM.
- Любой другой сервис карт (MapTiler, Stadia) подключается через `CUSTOM_TILES`.
- Если подложка не грузится, приложение само переключится на следующий источник.

## Название

Название приложения задаётся в `CONFIG.APP_NAME`, а также в `manifest.webmanifest` (`name`, `short_name`) и в `<title>`.

## Дальше: Android и iOS

Этот же код упаковывается в нативные приложения через **Capacitor**: веб-приложение внутри нативной оболочки, с публикацией в Google Play и App Store.

Что понадобится:
- Node.js 20+;
- Android Studio для Android;
- Mac с Xcode и аккаунт Apple Developer ($99 в год) для iOS;
- аккаунт Google Play Console ($25 один раз).

Перед сборкой стоит:
- перенести фото в Supabase Storage;
- поставить ключ CARTO: правила OpenStreetMap для мобильных приложений строже;
- подключить плагин геолокации Capacitor.
