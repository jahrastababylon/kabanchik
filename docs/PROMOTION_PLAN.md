# Tropami — план продвижения (старт: Краков → Польша → Европа)

Цель первых 8 недель: **300 установок и 100 наблюдений в Кракове**. Одна плотная карта в одном городе продаёт лучше, чем пустая карта Европы. Остальная Европа пока закрыта открытыми данными (GBIF).

## 0. Перед стартом (1–2 дня)
- Почистить тестовые данные, импортировать открытые наблюдения (см. SETUP_v8.md, раздел v10).
- Самим внести 20–30 настоящих наблюдений по Кракову: Błonia, Las Wolski, Zakrzówek, Bulwary, Park Jordana. Белки, ежи, лисы, птицы — с фото.
- Метки источников: в каждой ссылке добавлять `?src=…`. Пример: `tropami.com/app/?src=fb-krakow`. Источник первого входа пишется в событие `app_open` (поле `src`), отсюда видно, какой канал работает.
- Подготовить 5 коротких роликов (15–30 с): «dzik na osiedlu», «lis na Kazimierzu», «jak dodać obserwację w 10 sekund».

## 1. Неделя 1–2: локальные сообщества (бесплатно, самый высокий отклик)
| Канал | Что делать | src |
|---|---|---|
| Facebook-группы районов (Ruczaj, Bronowice, Prądnik, Nowa Huta, Podgórze…) | Пост с вопросом «widzieliście dziki/lisy na osiedlu? zróbmy wspólną mapę» + скрин карты района | `fb-<osiedle>` |
| Группы про природу/птиц Кракова, «Dziki w Krakowie» | То же, акцент на науке: «dane otwarte, eksport dla miasta» | `fb-natura` |
| Reddit r/krakow, r/Polska, Wykop #krakow #przyroda | Пост «zrobiłem darmową mapę dzikich zwierząt w mieście» — личная история создателя | `reddit`, `wykop` |
| Ornitologи: OTOP, koła PTOP, Klub Przyrodników | Письмо/сообщение: птицы теперь первые в форме, данные открытые | `otop` |

Правило: не спамить одинаковым текстом. Каждый пост — про конкретный район и реальную метку на карте.

## 2. Неделя 2–4: город и СМИ
- **Lasy Miejskie / Zarząd Zieleni Miejskiej Kraków, Straż Miejska (Ekopatrol)** — предложить карту встреч с кабанами как инструмент: тепловая карта по районам, экспорт. Партнёрство = упоминание на их страницах.
- **Пресс-релиз «Krakowianie mapują dziki»** в LoveKraków, Gazeta Krakowska, Radio Kraków, TVP3 Kraków. Повод — цифры: «za pierwszy miesiąc X obserwacji, najwięcej dzików na …». Тема кабанов в городе всегда заходит.
- **Школы и университеты**: UJ (biologia), UR (leśnictwo), koła naukowe. Мини-лекция / проект для класса: «tydzień obserwacji na osiedlu» — у школ это готовое задание по природе.

## 3. Неделя 3–8: соцсети и контент
- **TikTok / Instagram Reels / YouTube Shorts**, 3 ролика в неделю: животное в городе + «gdzie najczęściej widuje się…» по данным карты + юмор. Формат «mapa tygodnia» по пятницам.
- **Микроинфлюенсеры-натуралисты** (5–50 тыс. подписчиков, PL): бесплатный доступ, ранний значок «Ambasador», совместный челлендж. Начать с 5 человек.
- **Фотоконкурс месяца**: лучшее фото из приложения → репост + приз (книга-определитель, бинокль от партнёра).

## 4. Механики роста внутри приложения (следующие доработки)
- «Поделиться наблюдением» — красивая карточка-картинка с картой и ником (stories-формат).
- Реферальная ссылка: +30 XP обоим за друга, который сделал первое наблюдение.
- Еженедельный push «Na Twoim osiedlu w tym tygodniu: 3 jeże, 1 lis».
- Страницы городов для SEO: `tropami.com/krakow`, `/warszawa` — «dziki w Krakowie mapa», «gdzie zobaczyć lisa w Warszawie».

## Что измерять (Supabase SQL)
- `select * from analytics.funnel_new_user;` — открыл → ник → первое наблюдение.
- `select * from analytics.retention;` — возвращаются ли через 1/7/30 дней.
- По каналам:
  ```sql
  select props->>'src' src, count(distinct user_id) users
  from analytics.events where name='app_open' and props->>'src' <> ''
  group by 1 order by 2 desc;
  ```
- Ориентиры: ≥40% новых доходят до первого наблюдения, ≥20% возвращаются на 7-й день. Если ниже — сначала чинить продукт, потом лить трафик.
